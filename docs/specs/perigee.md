# Сессия Perigee: один умный режим вместо выбора из шести

До этой стадии Perigee знал о памяти пользователя только из самооценки во флэшкартах. Тест и игры
ничего ему не сообщали, сессия брала весь набор целиком, ошибка просто переносила слово на завтра,
а новые слова сразу попадали в самооценку, хотя человек видел их впервые. Сессия Perigee это
исправляет: короткая тренировка по всем наборам курса, формат задания зависит от того, насколько
слово уже выучено, ошибки возвращаются в той же сессии, и каждый ответ в любом режиме идёт в
расписание.

Аудит и этап A (сохранение оценок, офлайн, мягкая проверка теста) — коммит df32d51.

Решения пользователя (2026-11-12):

- сессия Perigee становится главной кнопкой на главной; старые режимы остаются в меню набора;
- **тест и игры тоже влияют на расписание**: первый ответ на слово за раунд идёт в Perigee.

---

## Из чего состоит сессия

| Параметр | Значение | Почему |
|----------|----------|--------|
| Слов в сессии | до 20 | 3–5 минут: можно сделать в очереди, не стена из 300 карточек |
| Новых слов за сессию | до 6 | две группы по три — столько удерживается в рабочей памяти |
| Новых слов в день | 12 | новые слова завтра вернутся повторением; без лимита через неделю повторений станет непосильно |

Порядок отбора (только активный курс, все его наборы):

1. **Слова к повторению** — самые просроченные первыми.
2. Если места осталось — **новые слова**, старые по дате добавления первыми, в пределах дневного лимита.

Дневной лимит считается по `srsData.introducedAt` — дате первой оценки слова (ставится в
`updateSRSData`). Поле живёт в документе набора, поэтому лимит общий для всех устройств. Слова,
впервые оценённые до этой стадии, поля не имеют и в лимит не идут.

Лимит исчерпан, а новые слова есть — главная говорит «на сегодня хватит» и предлагает «Ещё новые
слова»: `/learn?extra=1` берёт ещё до 6 новых в обход дневного лимита. Решает пользователь, но по
умолчанию бережём от перегрузки.

## Шаги

| Шаг | Что видит пользователь | Оценивается |
|-----|------------------------|-------------|
| `intro` | Новое слово: слово, часть речи, перевод, объяснение, пример, озвучка, «Дальше» | нет |
| `choice` | Слово → выбрать перевод (`forward`) или перевод → выбрать слово (`reverse`), 4 варианта | да |
| `type` | Перевод → написать слово; мягкая проверка из этапа A, «Не помню», «Мой ответ верный» | да |
| `flash` | Карточка наоборот: перевод → вспомнить слово → перевернуть → 4 оценки | да (самооценка) |

**Новое слово** проходит три шага: `intro` → `choice forward` → `choice reverse`. Новые идут группами
по три: сначала знакомство со всеми тремя, потом выбор для каждого, потом обратный выбор. Между
знакомством и проверкой — два других шага: это уже не кратковременная память.

**Слово к повторению** — один шаг, формат по силе памяти (`repetitions`):

| repetitions | Формат | Почему |
|-------------|--------|--------|
| 0 (вчера выучено или забыто) | `choice reverse` | узнать слово среди похожих — посильно, но уже не узнавание по-родному |
| 1 | `type`, если слово можно напечатать, иначе `flash` | первое настоящее вспоминание |
| 2 и больше | поровну `type` и `flash` | `type` — самое сильное вспоминание, `flash` — быстрый темп и честная самооценка |

«Можно напечатать» — не длиннее 30 символов и не больше 4 слов; длинные фразы печатать мучительно.

Слова к повторению распределяются между группами новых, чтобы сессия начиналась с разминки знакомыми
словами и чередовала форматы.

Варианты ответа в `choice` берутся из всех наборов курса, сначала с той же частью речи: «бежать» среди
трёх существительных угадывается методом исключения.

## Ошибка возвращается в той же сессии

Неверный ответ на любом шаге ставит **повтор** через три шага (или в конец, если осталось меньше).
Повтор не оценивается — это закрепление, а не проверка. Формат повтора: после `type` и `flash` —
`choice reverse` (полегче), после `choice` — тот же выбор с перемешанными вариантами. Слово
закрыто, когда на него ответили верно. Больше трёх повторов на слово не ставим, чтобы сессия
не зацикливалась.

## Что пишется в расписание

**Каждое слово получает ровно одну оценку за сессию (или раунд игры) — по первому ответу.**
Повторы после ошибки — обучение, а не память, и расписание не трогают.

Ответ переводится в оценку SM-2 одинаково во всех режимах (`levelForAnswer` в `src/utils/srs.ts`):

| Ответ | Оценка |
|-------|--------|
| выбор из вариантов: верно | «Помню» |
| выбор из вариантов: неверно | «Забыл» |
| ввод: точно | «Знаю» |
| ввод: почти (артикль, диакритика, опечатка) или «Мой ответ верный» | «Помню» |
| ввод: неверно или «Не помню» | «Забыл» |
| флэшкарта | оценка пользователя |

«Помню» слегка снижает лёгкость слова — поэтому слова, которые только узнают среди вариантов,
растут медленнее, чем те, что вспоминают сами. Правило повтора раньше срока из этапа A
(интервал растёт только по прошедшему времени) делает безопасными игры по кругу: верные ответы
на слово, которое ещё не пора повторять, расписание не сдвигают, а ошибка честно его сбрасывает.

Новое слово получает оценку после своего последнего шага: «Знаю», если ни одной ошибки, иначе
«Помню». Интервал в обоих случаях — 1 день, разница только в лёгкости.

**Тест**: оценивается первый ответ на каждое слово; «Пары» внутри теста — нет.
**«На скорость» и «Выживание»**: первый ответ на каждое слово за раунд (выбор из вариантов).
**«Пары»** в расписание не идут: шесть пар, последняя складывается сама — сигнал слишком слабый.

Запись идёт через общий `useSrsWriter` (вынесен из движка флэшкарт этапа A): пачкой, без ожидания
сети, при уходе со страницы, а на главной новые интервалы видны сразу.

## Итог сессии

Повторено, новых слов, точность с первого раза и прогноз: «Завтра ждут N слов» — по свежим
интервалам всех наборов курса. «Ещё сессия» собирает следующую, если есть что учить.

## Сервер

Новый вид тренировки `perigee` (`server/core/session.ts`, `xp.ts`):

- опыт — как у теста без бонуса за идеальный тест: 1 за слово + 1 за верный первый ответ;
- проверка правдоподобия — как у теста (слов не больше, чем в наборах ×2, не быстрее 0,8 с на слово);
- считается флэшкарт-сессией для достижений; «все знаю» — если все слова с первого раза.

`cards` — число разных слов, `correct` — сколько из них с первого раза.

## Не входит (дальше)

- настройка размера сессии и дневного лимита (сейчас — константы в `src/perigee/plan.ts`);
- пропуск в примере и аудирование (этап C);
- отмена в сессии Perigee (во флэшкартах есть с этапа A);
- переход Perigee с SM-2 на FSRS — когда накопится история ответов.
