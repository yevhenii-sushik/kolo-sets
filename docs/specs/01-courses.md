# Этап 1. Курсы

Курс — отдельное пространство под каждый изучаемый язык: наборы разных языков не смешиваются,
а при создании набора язык больше не спрашивается.

## Решения

- Один курс — один язык (`nb`, `it`, `en`…). Вариант произношения (en-US / en-GB, pt-BR / pt-PT,
  es-ES / es-MX…) — настройка курса, а не отдельный курс.
- Серия, опыт, лиги и достижения — общие на аккаунт. Курс — только пространство для слов.
- Новый пользователь без курсов сначала выбирает язык. Без курса дальше не пройти.
- Игра дня спрятана флагом `FEATURES.dailyGame` до многоязычной версии — и в приложении, и на лендинге.
- Готовая программа уроков — этап 5; модель курса оставляет для неё место.

## Модель данных

```ts
interface Course {
  id: string;        // код языка, он же id курса: 'nb', 'en', 'pt'…
  voice: string;     // BCP-47 для озвучки: 'nb-NO', 'en-GB', 'pt-BR'…
  addedAt: Date;
}
```

- **Профиль** (`users/{uid}`): `courses: Course[]`, `activeCourseId: string`, `coursesVersion: 1`.
  Хранится списком в профиле, как папки: курсов у человека единицы, правила базы менять не нужно.
- **Набор** (`users/{uid}/collections/{id}`): новое поле `courseId`. Старое поле `language` остаётся.
- **Папка** (`profile.folders[]`): новое поле `courseId`.
- **Цифры по курсу** (слов, выучено, к повторению) считаются из карточек и не хранятся.
  Время и опыт по курсам появятся вместе с сервером (этап 0/2).

`id` курса — код языка, поэтому курс не может появиться дважды, а миграция на двух устройствах
даёт одинаковый результат.

## Миграция существующих пользователей

Один раз после входа, на клиенте, если `coursesVersion` не задан:

1. Курсы = различные языки наборов (`nb-NO` → курс `nb`, голос `nb-NO`).
2. Каждому набору без `courseId` — курс по его языку (`updateDoc` только этого поля).
3. Каждой папке — курс большинства её наборов; пустой папке — активный курс.
4. Активный курс — курс последнего изученного набора (иначе самого большого).
5. В профиль пишутся `courses`, `folders`, `activeCourseId`, `coursesVersion: 1`.

Миграция только добавляет поля. Старая версия приложения (например, закэшированная PWA) продолжает
работать; если она создаст набор без `courseId`, новая версия при загрузке сама отнесёт его к курсу
по языку («самолечение»: та же процедура для отдельных наборов и папок без курса).

Пользователь без наборов курсов не получает и попадает на выбор языка.

## Какие экраны работают в рамках активного курса

| Экран | В рамках курса | Общее на аккаунт |
|-------|----------------|------------------|
| Главная | повторение, цифры слов и наборов, веха | серия, достижения, цель дня |
| Слова | наборы, папки, порядок | — |
| Повторение (`/review`) | карточки к повторению | — |
| Поиск | карточки курса | — |
| Профиль | — | всё: статистика, календарь, достижения |
| Данные и аккаунт | — | копия всех наборов всех курсов |

В `DataContext`: `collections` — наборы активного курса, `allCollections` — все.
Все записи списков (наборы, папки) идут через полный список, а не через отфильтрованный —
иначе сохранение папок или оптимистичное обновление стёрли бы данные других курсов.

## Интерфейс

- **Переключатель курса** в шапке: флаг варианта и название. Меню: курсы с числом слов,
  «Добавить курс», «Управление курсами».
- **Выбор языка** (первый вход и «Добавить курс»): поиск, популярные сверху, полный список ниже.
  Название на языке интерфейса и самоназвание; пометка, если на этом устройстве нет озвучки.
- **Страница «Курсы»** (`/courses`): список с цифрами, вариант произношения, удаление курса
  (подтверждение с числом наборов и советом сначала скачать копию).
- **Набор**: в меню — «Перенести в курс…» (если курсов больше одного).
- **Слова**: заголовок — название курса.

## Сопутствующие изменения

- **Части речи** хранятся нейтральным кодом (`noun`, `verb`, `adjective`…), подпись — на языке
  интерфейса. Старые норвежские значения (`substantiv`, `adjektiv`…) и сокращения готовых наборов
  (`n.`, `adj.`…) переводятся в коды при показе и при сохранении.
- **Озвучка** берёт голос из курса набора (раньше всегда `nb-NO`).
- **Письмо справа налево** (арабский, иврит, фарси, урду): `dir="auto"` у слов, переводов, примеров и полей.

## Каталог языков

`src/courses/languages.ts`: около 60 языков. Для каждого — код, варианты произношения с флагом
страны, направление письма, признак «популярный». Названия — через `Intl.DisplayNames`,
поэтому каталог не нужно переводить вручную. Языков без устойчивой «своей» страны
(эсперанто, латынь, баскский…) — значок с буквами вместо флага.

## Вне этого этапа

- Программа уроков (этап 5), опыт и лиги по курсам (этапы 0–3).
- Отдельная серия по каждому курсу — не выбрана.

## Проверка

- QA-аккаунт с наборами без курсов → миграция → всё на месте, папки и порядок сохранены.
- Новый QA-аккаунт → выбор языка → пустой курс → создание набора без вопроса о языке.
- Два курса → переключение, поиск, повторение, перенос набора, удаление курса.
- Старая версия приложения создаёт набор → новая относит его к курсу.
- Светлая и тёмная тема, телефон и десктоп, en/ru/uk/no.
