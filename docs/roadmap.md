# Kolo — дорожная карта до большого релиза

Документ для команды Kolo: что строим, в каком порядке и какие решения уже приняты.
Подробные схемы отдельных этапов — в `docs/specs/`.

## Принципы

- **Прогресс начисляет сервер.** Очки, серии, достижения и награды пишет не браузер, а серверные функции.
  Иначе редкие награды и рейтинги можно подделать из консоли браузера.
- **Награды — только за занятия.** Никаких платных случайных наград (лутбоксов): это противоречит
  обещанию «всё обучение бесплатно», и в Норвегии и ЕС такие механики под вниманием регуляторов.
- **Приватность по умолчанию.** Соцфункции — с настройками видимости профиля, блокировкой и жалобами.
- **Все тексты интерфейса — сразу на en/ru/uk/no**, публичные страницы — на 8 языках.
- **Каждый этап — отдельная ветка**, проверка на тестовом адресе Netlify
  (`<ветка>--dakuta-kolo.netlify.app`) тестовыми аккаунтами, затем слияние в `main`.
  Тестовые адреса работают с рабочей базой Firebase.

## Этапы

| # | Этап | Статус |
|---|------|--------|
| 0 | Сервер: Firebase Cloud Functions, начисление прогресса на сервере, закрытые правила базы | Отложен: нужен тариф Blaze |
| 1 | Курсы: отдельное пространство под каждый изучаемый язык | В работе — `docs/specs/01-courses.md` |
| 2 | Опыт, «ударный режим» (недельные орбиты, щиты, починка), лутка и коллекции наград | После этапа 0 |
| 3 | Друзья, совместная серия, дуэли, недельные лиги, клубы | После этапа 2 |
| 4 | Сезоны и события с ограниченными наградами | После этапа 3 |
| 5 | Готовые программы уроков внутри курсов (контент — команда Kolo) | После этапа 1, контент параллельно |

## Принятые решения (2026-11-06)

- **Сервер** — Firebase Cloud Functions (тариф Blaze с бюджетным оповещением). Пока тариф не включён,
  делаем то, что не требует сервера.
- **Курс** — изучаемый язык. Внутри — свои наборы и папки, позже — готовая программа уроков Kolo.
- **Варианты языка** (английский US/UK, португальский BR/PT…) — настройка произношения внутри одного курса.
- **Новый пользователь** первым делом выбирает язык; без курса дальше не пройти.
- **Игра дня** (только норвежские слова) спрятана до многоязычной версии.
- **Ударный режим** — недельные орбиты (цель — N дней в неделю, серия — недели подряд),
  щиты и починка серии, совместная серия с другом. Серия общая на аккаунт, не по курсам.
- **Соревнования** — недельные лиги, дуэли с друзьями, сезоны и события, клубы.
