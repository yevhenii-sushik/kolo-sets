# Kolo Sets - Language Learning App 🎴

Минималистичное приложение для изучения норвежского языка с использованием интервальных повторений (SRS).

- ✅ **3 языка**: 🇬🇧 English, 🇳🇴 Norsk, 🇷🇺 Русский
- ✅ **Главная страница** полностью переведена
- ✅ **Навигация** на всех языках
- ✅ **Создание коллекций** переведено
- ✅ **Мгновенное переключение** без перезагрузки

- ✅ Норвежский (Bokmål и Nynorsk)

## 🌐 Как переключить язык

1. Откройте приложение
2. Нажмите на иконку 🌐 в правом верхнем углу
3. Выберите язык:
   - 🇬🇧 English
   - 🇳🇴 Norsk  
   - 🇷🇺 Русский
4. Интерфейс обновится мгновенно!

## 💻 Для разработчиков

### Добавить перевод в компонент:

```typescript
import { useI18n } from '../contexts/I18nContext';

function MyComponent() {
  const { t } = useI18n();
  
  return (
    <div>
      <h1>{t.home.title}</h1>
      <button>{t.create}</button>
      <p>{t.home.description}</p>
    </div>
  );
}
```

### Изменить язык программно:

```typescript
const { setLanguage } = useI18n();
setLanguage('no'); // 'en', 'no', или 'ru'
```

### Все переводы находятся в:
`src/utils/i18n.ts` - 200+ строк на 3 языках
