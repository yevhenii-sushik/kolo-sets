## 📊 Технические детали:

### Что делает скрипт в index.html:

```javascript
// 1. Находит все Service Workers
navigator.serviceWorker.getRegistrations()

// 2. Удаляет каждый
registration.unregister()

// 3. Очищает все кэши
caches.keys().then(names => {
  names.forEach(name => caches.delete(name))
})
```

### Когда запускается:
- При каждой загрузке страницы
- Работает молча в фоне
- Не мешает работе приложения
