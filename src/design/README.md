# Дизайн-система Kolo

Направление «Орбита»: ночной синий, оранжевый Kolo и кольцо как фирменный знак (коло — круг повторения).

- **Токены** — `src/design/tokens.css`: единственный источник цветов, шрифтов, скруглений и теней.
- **Компоненты** — `src/ui`: `import { Button, Card, Heading } from "../ui"`.
- **Витрина** — маршрут `/design` (только `npm run dev`): все токены и компоненты вживую, в обеих темах.
- **Проверка** — `npm run check:design`; запускается автоматически перед `npm run build`.

## Цвета

Только семантические имена, а не hex и не палитра Tailwind. Тёмная тема переключается сама: токены переопределены под `.dark`, поэтому `dark:`-варианты для цвета не нужны.

| Токен | Для чего |
|---|---|
| `bg` | фон страницы |
| `band` | чередующиеся полосы на длинных страницах |
| `surface` | карточки, меню, модальные окна |
| `inset`, `subtle` | поля ввода и вложенные блоки внутри карточек |
| `track` | дорожки прогресса, орбиты, выключенные переключатели |
| `line` | рамки и разделители |
| `scrim` | затемнение под модалками, всегда с прозрачностью: `bg-scrim/50` |
| `fg` | основной текст; он же фон инверсного блока |
| `on-inverse` | текст на `bg-fg` |
| `muted` | второстепенный текст |
| `faint` | подписи, метки, иконки в спокойном состоянии |
| `hint` | плейсхолдеры и декоративные подписи |
| `accent` | фирменный оранжевый: заливки, иконки, кольца |
| `accent-hover`, `accent-deep` | наведение; «дно» объёмных кнопок |
| `on-accent` | текст на оранжевом — тёмный, контраст 6,2 : 1 |
| `accent-ink` | оранжевый **текст** и ссылки на светлом фоне, контраст 5,6 : 1 |
| `accent-soft` | мягкая оранжевая подложка |
| `brand-night`, `brand-orange` | не меняются в тёмной теме: иконка приложения и блоки, которые всегда тёмные. В остальном интерфейсе — `fg` и `accent` |
| `danger`, `success`, `warning`, `info`, `special` | состояния; `special` — витрина наборов Kolo Sets |
| `*-soft` | подложки под состояния: `bg-danger-soft text-danger` |

Прозрачность — модификатором: `bg-accent/10`, `border-danger/30`.

## Типографика

- **Шрифты:** `font-display` (Nunito, вес `font-extrabold`) — заголовки экранов и секций, крупные цифры и логотип; всё остальное — Onest (по умолчанию).
- **Размеры:** только шкала `text-2xs` (11px, для плотных меток) · `text-xs` (12) · `text-sm` · `text-base` · `text-lg` · `text-xl` … Основной минимум — `text-xs`.
- **Начертания:** текст Onest — `font-medium`, `font-semibold`, `font-bold`; заголовки Nunito — `font-extrabold`. Без `font-black`.
- **Капс** — только в `Eyebrow` (короткая метка над заголовком). Кнопки, подписи полей и заголовки — обычным регистром.
- Заголовки — через `Heading` (`size="display" | 1 | 2 | 3 | 4`, `tone="inverse"` на `bg-fg`), текст — через `Text` (`tone`, `size`; `tone="inverse"` — второстепенный текст на `bg-fg`).

## Форма

- **Скругления:** `rounded-lg` (10) · `rounded-xl` (12) · `rounded-2xl` (16) · `rounded-3xl` (20) · `rounded-4xl` (24) · `rounded-full`. Кнопки — `rounded-full`, поля — `rounded-2xl`, большие карточки — `rounded-4xl`. Для макетов телефона — `rounded-phone` (корпус) и `rounded-phone-screen` (экран).
- **Тени:** `shadow-xs` … `shadow-2xl` (мягкие, с оттенком ночного синего). Тень — для того, что парит (меню, модалки, плавающие кнопки); обычной карточке хватает рамки `border-line`.

## Компоненты (`src/ui`)

| Компонент | Когда |
|---|---|
| `Button` | действие. `variant`: `primary` (одно главное на экран), `inverse`, `secondary`, `soft`, `ghost`, `danger`; `size`: `sm`/`md`/`lg`; `loading`, `iconLeft`/`iconRight`, `fullWidth` |
| `ButtonLink` | переход по маршруту, который выглядит как кнопка |
| `IconButton` | кнопка-иконка; `label` обязателен (скринридер, подсказка) |
| `buttonStyles()` | классы кнопки для нестандартного элемента |
| `Field` + `Input` / `Textarea` / `Select` | поле с подписью, подсказкой и ошибкой; `Select` — нативный список |
| `Checkbox`, `Switch` | флажок с подписью; переключатель (с `label` для скринридера) |
| `Card` | `tone`: `surface`, `inset`, `inverse` (один акцент на экран), `accent` |
| `Heading`, `Text`, `Eyebrow` | типографика |
| `Badge` | короткая метка состояния; `tone` как у состояний |
| `Ring` | прогресс по кругу — фирменный элемент; `label` обязателен |
| `Modal` | модальное окно: затемнение, Esc, на телефоне снизу |
| `Spinner` | загрузка (цвет — от текста вокруг) |
| `Alert` | сообщение над формой: `tone` `danger` (по умолчанию, зачитывается скринридером сразу), `success`, `info`, `warning` |
| `Logo`, `LogoMark`, `AppIcon` | знак Kolo, см. ниже |
| `PerigeeMark` | знак движка повторений Perigee, см. «Знак Perigee» |

## Знак

«Орбита» — кольцо и спутник: слово уходит на орбиту и возвращается, когда его пора повторить. Геометрия — в `src/ui/Logo.tsx`.

- **`Logo`** — знак с надписью «kolo» (`size`: `sm`/`md`/`lg`). Обычно внутри ссылки на главную с классом `group`: при наведении спутник делает оборот.
- **`LogoMark`** — знак без надписи. Если он стоит один и не внутри подписанной ссылки, передайте `label`.
- **`AppIcon`** — знак на ночном квадрате, как на домашнем экране (онбординг, макеты телефона).
- **`tone`**: `brand` — обычный фон; `inverse` — на `bg-fg`; `night` — на `bg-brand-night` (тёмный в обеих темах, подвал сайта); `mono` — один цвет от текста вокруг (на оранжевом).
- **Название:** в логотипе — «kolo» строчными. Во вкладке, превью ссылок и выдаче поиска — «Kolo» (теги в `index.html`, у публичных страниц — `usePageMeta` из `src/utils/pageMeta.ts`). «Kolo Sets» пока остаётся в юридических документах, подвалах и строке версии.
- **Нельзя:** вставлять знак картинкой, перекрашивать кольцо, растягивать, поворачивать (кроме оборота спутника), добавлять тени и обводки. Меньше 16 px знак не используется.

### Знак Perigee

У движка повторений свой знак, `PerigeeMark` — «Апсида»: крылья цвета текста и оранжевая точка под вершиной. Крылья — тяжёлая дуга перигея (толще у вершины, иглы на концах), точка — ученик, к которому слово подходит ближе всего. Колец в нём нет намеренно: Kolo — приложение, Perigee — движок, один знак на двоих не делим.

- Ставится только там, где речь о Perigee: плашка в блоке «Методика» на лендинге, страница `/perigee`. Везде, где речь о приложении, — знак Kolo.
- `tone` — как у `LogoMark`. Меньше 24 px точка крупнее (это уже заложено в компоненте). Меньше 16 px знак не используется.
- **Нельзя:** перекрашивать крылья в оранжевый, поворачивать, ставить в кольцо или рядом со знаком Kolo как один логотип.

Файлы в `public/` собраны из той же геометрии, фон `brand-night`, кольцо `brand-orange`, спутник белый:

| Файл | Где | Знак |
|---|---|---|
| `favicon.svg`, `favicon.ico` (16 + 32) | вкладка браузера | квадрат со скруглением 22 %, знак 84 % |
| `apple-touch-icon.png` (180) | iOS, «На экран Домой» | квадрат без скругления, знак 66 % |
| `icon-192.png`, `icon-512.png` | манифест PWA | квадрат со скруглением 22,4 %, знак 69 % |
| `icon-maskable-512.png` | Android, обрезка по форме | квадрат без скругления, знак 58 % (в безопасной зоне) |
| `badge-96.png` | значок уведомления | белый знак на прозрачном |
| `og-image.png` (1200×630) | превью ссылок | ночной фон, «kolo», заголовок, подпись, плашки «Free · No ads · Browser & phone», крупный знак. После замены подними `?v=` в `index.html` |

Если знак меняется — пересоберите все эти файлы.

## Нельзя

Проверка `check:design` остановит сборку, если найдёт:

- hex в классах (`bg-[#FF5733]`, `shadow-[0_2px_0_#123]`) — используйте токен или `var(--color-…)`;
- палитру Tailwind (`text-red-500`, `bg-gray-100`) — используйте токены состояний;
- произвольный размер текста (`text-[13px]`) и скругление (`rounded-[2.5rem]`);
- `scrim` для текста, рамок и заливок SVG — он только для затемнения под модалками;
- `font-black`, `font-serif`.

Ещё одна ловушка, которую проверка не ловит: класс видимости (`hidden`, `block`) в `className` компонента набора не перебивает его собственный `inline-flex` — побеждает тот, что позже в CSS. Прятать кнопку на узком экране — обёрткой: `<span className="hidden sm:contents"><Button …/></span>`.

Исключения — цвета чужих брендов (Woky, Bøy!, кнопка Google) в списке `BRAND_HEX` в `scripts/check-design.mjs`.

## Как добавить токен

1. Добавьте переменную в `@theme` в `tokens.css` и её тёмное значение в блок `.dark`.
2. Проверьте контраст текста: не ниже 4,5 : 1 на фоне, где он используется.
3. Добавьте имя в витрину (`src/pages/design/DesignPage.tsx`, `COLOR_GROUPS`).
